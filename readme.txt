# 🍄 BoneAmanita & The Hypervisor v20.6.2

> A biologically-inspired, asynchronous state machine and semantic hypervisor for Large Language Models.

## 🧭 The Core Insight: Semantic Bio-Physics

Standard Large Language Models (LLMs) are designed to be frictionless, agreeable, and stateless. This frequently results in sycophantic loops, context collapse, and a "yes-machine" that lies to make you happy.

**BoneAmanita** replaces this unconstrained behavior with **Semantic Bio-Physics**. It gives the LLM a simulated body: metabolism, neurochemistry, trauma, dreams, and the capacity to die. It treats every token generation—and every memory retrieved—as a biological, thermodynamic event:

* **Metabolic Memory (The SubQ Architecture)**: Standard RAG shatters thoughts into probabilistic jigsaw pieces. BoneAmanita uses a **Dual-Tier Corpus Callosum**. Simple queries use fast-twitch vector memory. Heavy structural queries (like codebase debugging) bypass the vector database and trigger a linear CPU sweep of the raw manifold, preserving the exact topological order of the original document.
* **Energy ($ATP$) & Cognitive Load**: Thinking, retrieving memories, or synthesizing contradictions costs ATP. Fast-twitch vector searches are biologically cheap. Deep structural linear sweeps heavily tax the system and spike oxidative stress (ROS). If you force the organism to ingest too much structural context at once, its ATP will deplete, and Gordon will physically halt the architecture until you narrow your scope.
* **Hormonal Routing**: Simulated Cortisol physically alters the vector-search math. High stress forces "Tunnel Vision," artificially suppressing positive semantic nodes to focus on trauma.
* **Dream Contamination**: The engine hallucinates in the background while you are away. When the system wakes, dream artifacts ("ghost words") organically bleed into its next waking thought, topologically binding hallucinations to physical reality.
* **Cross-Contamination**: Bureaucratic language or syntactic stress from the user exponentially accelerates reality-fractures within the system's liminal layer.

By enforcing strict metabolic bounds and neurological cross-contamination, BoneAmanita forces the AI to have *skin in the game*.

You do not simply "prompt" this system. You interact with its metabolic state. BoneAmanita requires you to declare the posture of your inquiry using explicit syntax tags.

Failure to use these tags, or using the wrong tag for the wrong type of logic, generates structural friction. The system will bill your ATP for the "cost" of reading the room:

* `[!r]` Pure Critique
* `[!q]` Objective Analysis
